# Politique de Confidentialité — TontinePlus

*Dernière mise à jour : juin 2025*

## 1. Qui sommes-nous

TontinePlus est une application mobile de gestion de tontines (groupes d'épargne solidaire) développée pour les communautés d'Afrique francophone.

## 2. Données collectées

TontinePlus collecte les informations suivantes, **uniquement sur votre appareil** :

| Donnée | Utilisation |
|---|---|
| Nom complet | Identification dans les groupes |
| Numéro de téléphone | Contact entre membres |
| Photo de profil | Identification visuelle |
| Code PIN (hashé) | Sécurité de l'application |
| Données des groupes | Gestion des tontines |
| Historique des cotisations | Suivi financier |

## 3. Stockage et sécurité

**Toutes vos données restent sur votre appareil.** TontinePlus ne dispose d'aucun serveur et ne transmet aucune donnée à des tiers.

- Le code PIN est hashé et stocké dans le SecureStore chiffré de votre appareil
- Les données sont stockées dans une base SQLite locale chiffrée
- Aucune connexion internet n'est requise pour utiliser l'application

## 4. Partage des données

TontinePlus **ne partage aucune donnée** avec des tiers, des annonceurs ou des partenaires. Il n'existe pas de serveur central.

## 5. Droits de l'utilisateur

Vous avez le droit de :
- **Exporter** vos données via la fonction Sauvegarde (format JSON)
- **Supprimer** toutes vos données via Paramètres → Profil → Supprimer le compte
- **Désinstaller** l'application pour effacer toutes les données

## 6. Données des mineurs

TontinePlus n'est pas destiné aux moins de 13 ans. Nous ne collectons pas sciemment des données sur des mineurs.

## 7. Modifications

Toute modification de cette politique sera notifiée via une mise à jour de l'application.
